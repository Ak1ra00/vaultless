What is the entropy vulnerability?
ColdCard Mk3, Mk4, and Mk5 devices running firmware before certain versions had a weak pseudo-random number generator (PRNG) that could be brute-forced. The seed generation relied on this PRNG instead of true hardware randomness.

**Why it matters:** A weak PRNG can only produce ~40-72 bits of entropy, while the security standard for Bitcoin wallets is 128 bits. This means an attacker could theoretically guess your seed.
How dice rolls help
Each die roll provides approximately 2.585 bits of true entropy (from 6-sided randomness). Using dice rolls during wallet setup adds this true random entropy to the seed generation process, making brute-force attacks computationally infeasible.

**Example:** 50 dice rolls = ~129 bits of entropy, which exceeds the security threshold.
Firmware update recommendations
**Mk1:** All firmware versions are safe
**Mk2/Mk3:** Update to firmware 4.2.0+
**Mk4/Mk5:** Update to firmware 5.6.0+
**Q:** Update to firmware 1.5.0Q+

These updates include fixes for the entropy vulnerability and proper hardware random number generation.
